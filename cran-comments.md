## Resubmission

This is a resubmission of `kuzuR`. The version has been bumped to `0.2.5`.

### Summary of Changes

*   The upstream Python package `kuzu` has been archived.
    As a result, `kuzuR` can no longer be used and will be archived as well.
*   `kuzuR` is now deprecated. A deprecation message is shown on package load,
    directing users to the replacement package `lbugr`.
*   The README has been updated with a deprecation notice at the top.
